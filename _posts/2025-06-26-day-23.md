what_i_learned: |
  Today I explored and deepened my knowledge on meta loss or meta training loss in order to get a overall better idea of what it means. It starts with the support set which is the inner loop that adapts the models parameters and then the query set which evaluates those parameters as the outer loop. The meta training loss is the average loss on the query set, so it tells you how much mistakes the model makes. I learned how to combat my problem of my meta loss being unstable and one of those problems happened to be a gradient explosion which signified that my gradients were to large. I ended up fixing this by limiting the size of each update step by using clip_grad_norm_().
